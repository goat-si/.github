<h1 align="center">GOAT</h1>

<p align="center">
  One control surface for the coding agents on all your machines.<br/>
  <a href="https://trygoat.ai">trygoat.ai</a> · <a href="https://github.com/goat-si/goat">Source</a> · <a href="https://github.com/goat-si/goat/releases">Releases</a>
</p>

---

GOAT runs your existing **Claude Code, Codex, Cursor, Grok Build, OpenCode and Google Antigravity** setups, lets you review their changes, and keeps the work reachable from your laptop, cloud VMs and phone.

- **Global agent** that works across projects and threads
- **SSH hosts as first-class environments**: GOAT ships its runtime to the host and follows threads there
- **MCP server** with `goat_*` tools, so outside agents can drive GOAT
- **Desktop, web and mobile** clients
